# 快速分析模式（Quick Mode）

当用户只想在短时间内建立项目认知时，按以下顺序输出，不必强行完成完整报告：

1. **项目定位（1–2段）：** 它解决什么问题，输入输出是什么。
2. **核心思想（要点）：** 用不超过 5 个步骤讲清算法。
3. **架构地图：** 识别主要模块、核心 API、关键依赖。
4. **最短源码路径：** 给出 5–10 个关键文件/函数，按阅读顺序排列。
5. **一次端到端调用链：** 从入口追踪到结果输出。
6. **值得注意的限制：** 列出已验证的局限、未验证事项。
7. **下一步建议：** 推荐一个最有价值的深入方向。

快速模式仍然必须检查真实源码。若只看了 README，应明确写“仅基于文档的初步判断”，不得称为源码分析。
